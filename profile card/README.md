## 🌟 About This Project

This project is a visually stunning and responsive profile card for **Cristiano Ronaldo**. It highlights his incredible achievements, massive fan base, and his iconic legacy. The design features a premium glassmorphism effect, vibrant glowing borders, and a beautiful layout that brings the card to life! ✨

## ✨ Key Features

- 🖼️ **Stunning Profile Picture**: A crisp and focused image of Cristiano Ronaldo holding the Ballon d'Or.
- 📖 **Inspiring Biography**: Highlights his status as a football legend, his athletic prowess, relentless work ethic, and his 5 Ballon d'Or awards.
- 🌌 **Dynamic Background**: The background beautifully showcases him with the iconic UEFA Champions League trophy, celebrating his 5 UCL victories.
- 📊 **Live Stats Display**: 
  - 👥 **Followers**: 678M
  - ⚽ **Goals**: 974
- 🖱️ **Interactive Social Action**: A vibrant, hover-responsive "Follow" button featuring an Instagram icon.

## 🛠️ Technologies Used

- **HTML5**: Structured with semantic tags for a clean layout.
- **CSS3**: Styled with modern CSS techniques including:
  - 💎 Glassmorphism (blur effects)
  - 🌈 Beautiful gradients and glowing borders
  - 📐 Flexbox for perfect alignment
  - ✨ Custom typography

## 🚀 How to Run

It's super easy! No installations required. 
1. Simply download or clone the repository.
2. Navigate to the `profile card` folder.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
