# Cristiano Ronaldo (CR7) Profile Card

A sleek and visually appealing profile card dedicated to Cristiano Ronaldo, one of the greatest footballers of all time. 

## 🌟 Features

- **Profile Picture**: Features a crisp image of Cristiano Ronaldo.
- **Biography**: A short description highlighting his status as a football legend, his athletic prowess, relentless work ethic, and his 5 Ballon d'Or awards.
- **Dynamic Background**: The background showcases him with the iconic UEFA Champions League trophy, celebrating his 5 UCL victories.
- **Stats Display**: 
  - **Followers**: 678M
  - **Goals**: 974
- **Social Action**: A vibrant "Follow" button linked with the Instagram theme.

## 🛠 Tech Stack
- **HTML5**: For structuring the card.
- **CSS3**: For styling, layout, typography, and visual effects (glassmorphism, gradients, borders).

## 🚀 How to Use
Simply open the `index.html` file in any modern web browser to view the profile card.
