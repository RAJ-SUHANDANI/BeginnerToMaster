## 🌸 About This Project

This folder is for projects that start from the basics and go all the way to advanced levels! **Travel Explorer** is our very first project, and it's designed to master the fundamentals of web structure.

> **The fastest way to get good at HTML is to build a real webpage without relying on CSS or JavaScript!** 💖

## 🏆 HTML Challenge: Build a "Travel Explorer" Website

**🌱 Difficulty:** Beginner ➡️ Intermediate  
**🎯 Goal:** Use almost every important HTML tag you've learned.

### ✨ Rules:
- ✅ **Only HTML**
- ❌ **No CSS**
- ❌ **No JavaScript**
- 🏷️ Use **semantic HTML** wherever possible.
- 🖼️ Use only publicly available images/videos.

---

# What to Build

Create a website for a fictional travel company called:

> **Travel Explorer**

The website should contain the following sections.

---

# 1. HTML Boilerplate

Include

* `<!DOCTYPE html>`
* `<html>`
* `<head>`
* `<title>`
* meta charset
* viewport meta

---

# 2. Header

Use

* `<header>`
* `<h1>`
* `<p>`

Example

```
Travel Explorer
Explore the world one destination at a time.
```

---

# 3. Navigation

Use

* `<nav>`
* `<ul>`
* `<li>`
* `<a>`

Links

* Home
* Destinations
* Packages
* Gallery
* Contact

Use internal page links (`#id`).

---

# 4. Hero Section

Use

* `<section>`
* `<h2>`
* `<p>`
* `<img>`

Include one large travel image.

---

# 5. About Us

Use

* `<article>`
* `<h2>`
* `<p>`
* `<strong>`
* `<em>`
* `<mark>`
* `<abbr>`
* `<br>`
* `<hr>`

Mention:

* Company started in 2020
* 50+ destinations
* Thousands of happy travelers

---

# 6. Popular Destinations

Use

* `<section>`
* `<figure>`
* `<img>`
* `<figcaption>`

Create cards for

* Paris
* Bali
* Switzerland
* Dubai

---

# 7. Travel Packages Table

Use

* `<table>`
* `<caption>`
* `<thead>`
* `<tbody>`
* `<tfoot>`
* `<tr>`
* `<th>`
* `<td>`

Columns

* Package
* Days
* Price
* Meals Included

Include at least 5 rows.

---

# 8. Why Choose Us

Use

* Ordered list
* Unordered list
* Nested list

Example

```
✔ Affordable

✔ Experienced Guides

✔ 24/7 Support

✔ Custom Tours
    - Family
    - Solo
    - Honeymoon
```

---

# 9. Testimonials

Use

* `<blockquote>`
* `<cite>`
* `<q>`

Include at least 3 testimonials.

---

# 10. Travel Tips

Use

* `<details>`
* `<summary>`

Create 5 expandable tips.

---

# 11. Embedded Video

Use

* `<iframe>`

Embed a YouTube travel video.

---

# 12. Audio Section

Use

```
<audio controls>
```

Include relaxing travel music or nature sounds.

---

# 13. Image Gallery

At least 6 images using

* `<img>`
* `<figure>`
* `<figcaption>`

---

# 14. Favorite Destinations Form

Use almost every important form element.

Include

* `<form>`
* `<label>`
* `<input>`

Types

* text
* email
* password
* tel
* number
* date
* time
* color
* range
* file
* url
* search
* radio
* checkbox
* hidden

Also use

* `<textarea>`
* `<select>`
* `<option>`
* `<optgroup>`
* `<fieldset>`
* `<legend>`
* `<button>`
* `<datalist>`

Validation

* required
* minlength
* maxlength
* placeholder
* readonly
* disabled

---

# 15. Contact Information

Use

* `<address>`

Include

* Email
* Phone
* Office Address

---

# 16. Footer

Use

* `<footer>`

Include

* Copyright
* Social links
* Email link (`mailto:`)
* Phone link (`tel:`)

---

# 17. Bonus Section (Use Rare HTML Tags)

Try including these too.

```
<code>
<pre>
<kbd>
<samp>
<var>
<small>
<sup>
<sub>
<time>
<del>
<ins>
<bdo>
<dfn>
```

Example ideas:

* Show keyboard shortcut with `<kbd>`
* Show sample terminal output with `<samp>`
* Write a mathematical formula using `<sup>` and `<sub>`
* Display the current year with `<time>`
* Show an updated price using `<del>` and `<ins>`
