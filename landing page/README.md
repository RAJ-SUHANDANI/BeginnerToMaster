# GreenCycle 🌍

Welcome to **GreenCycle**, a modern, responsive, single-page HTML landing page designed for an environmental non-profit organization. Our mission is to promote recycling, sustainability, and environmental awareness through a cute, premium, and eco-friendly web presence.

## ✨ Features

- **Single-file HTML project:** Everything you need in one place.
- **Embedded CSS only:** No external stylesheets required.
- **Responsive design (mobile-first):** Looks great on all devices.
- **Sticky glassmorphism navigation bar:** Modern UI touches for a premium feel.
- **Full-screen hero section:** Captivating first impression.
- **Animated floating background blobs:** Dynamic and engaging background effects.
- **Smooth scrolling:** Enhances user experience navigating the page.
- **Hover animations:** Interactive elements that respond to the user.
- **CSS Grid and Flexbox layouts:** Robust and modern structural design.
- **Google Fonts (Poppins & Inter):** Clean, accessible typography.
- **CSS Variables:** Easy customization for colors, spacing, and typography.
- **Modern gradients and soft shadows:** Adds depth and a polished look.
- **Rounded UI components:** Cute and friendly aesthetic.
- **Decorative emojis:** Lightweight alternatives to heavy icon libraries.
- **Newsletter subscription section:** To help grow your community.
- **Beautiful footer:** Complete with social links.
- **Fully semantic HTML5 structure:** SEO and accessibility friendly.
- **Zero JavaScript frameworks:** Blazing fast performance.
- **No external dependencies:** (Except for Google Fonts)

GreenCycle is built with a **mobile-first** approach. The layout gracefully adapts to provide an optimal viewing experience across a wide range of devices:

## 🎯 Customization

GreenCycle is highly customizable thanks to the heavy use of CSS Variables defined at the top of the embedded stylesheet.

- **Colors & Fonts:** Modify the `:root` variables in `index.html` to instantly change the theme.
- **Text & Images:** Simply edit the HTML tags to replace placeholder content.
- **Sections:** Add, remove, or reorder `<section>` tags.
- **CSS Variables Example:**
  ```css
  :root {
      --primary-color: #6C9E7A;
      --secondary-color: #FFD166;
      --font-main: 'Poppins', sans-serif;
  }
  ```
