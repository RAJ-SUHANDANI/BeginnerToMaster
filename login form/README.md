# Login Form

A beautiful, modern login form built using pure HTML and CSS.

## Features
- **Clean and Modern UI:** A visually appealing design with a soft color palette and clear typography.
- **Form Validation:** Basic HTML5 validation for email and password fields.
- **Social Login Options:** Dedicated buttons for logging in with Google and Apple, complete with SVG icons.
- **Password Visibility Toggle:** Includes an eye icon for future javascript integration to toggle password visibility.
- **Responsive Design:** Adapts smoothly to different screen sizes.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- SVGs for Icons

## Usage
Simply open `index.html` in your web browser to view the login form.
