# Signup Form

A stunning and modern signup form built with HTML and CSS, matching the aesthetic of the login form.

## Features
- **Elegant UI Design:** Consistent with the login form, featuring soft backgrounds and styled input fields.
- **Comprehensive Fields:** Includes inputs for Email Address, Password, and Confirm Password.
- **Social Signup:** Buttons to easily sign up using Google or Apple.
- **Fully Styled Components:** Beautifully designed buttons and SVG icons for a premium feel.
- **Responsive Layout:** Designed to look great on any device.

## Technologies Used
- HTML5
- CSS3 (Vanilla)

## Usage
Simply open `index.html` in your web browser to view the signup form.
